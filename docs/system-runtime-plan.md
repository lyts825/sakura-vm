## 实施约束

- 统一治理层不替代领域锁、运行票据、namespace/cgroup清理或数据恢复日志。
- 资源申请一次原子预留所有维度；排队期间不持有部分预算。
- 取消信号不等于清理成功；只有实际退出/流关闭/协议确认后才释放相应额度。
- 任务展示历史不作为副作用执行承诺。恢复由领域handler核对回执；未知结果保留待核对状态。
- 非可信代码隔离依赖实际运行边界，类型能力接口不宣称操作系统安全沙箱。
- 每一批以真实调用路径及相应测试为完成依据，最终逐项审计全表。
