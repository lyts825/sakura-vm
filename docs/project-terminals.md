# 项目终端与只读分享

Sakura 的普通网页终端使用所选项目的持久 UID/GID、独立 home、原目录及共享客户机网络或仅回环的项目网络空间。未显式传入项目时，服务端读取保存的活动项目；停用项目插件后也遵守该配置。既有 root 目录必须先通过项目权限面板核对并应用原目录迁移计划，账号未就绪时不会运行交互命令。

每条普通连接或持久会话使用独立的 tmux 服务器和 cgroup。启用“多终端工作区”后，会话、标签、选中项及分屏布局分别按实例和项目保存。首次连接可准备 tmux、iproute2、目录及私有网络空间；系统包下载使用客户机共享网络，不加载项目环境变量。切换项目后原有命名会话继续运行，返回原项目可恢复历史。tmux 服务器在项目账号下创建全部新窗口、分屏和子进程，继承同一账号、home、网络空间和运行域。

宿主在启动前持久登记随机运行 UUID、完整账号身份与开机身份，再记录完整原生运行票据。客户机 root 回执固定目录、socket、服务器 PID/创建时间及实际会话 ID；socket 目录在开启项目 Shell 前封闭为 root 所有、仅原项目 GID 可访问。重连和共享检查服务器及所有窗格的真实 UID/GID、创建身份、网络 inode 和完整 cgroup，旧会话被替换时拒绝连接。SSH 只携带固定控制器及身份元数据；控制器经独立管道发送有界保护帧，原生启动器完整验收、降权后才复制已打开的 PTY，不会修改 root PTY 文件权限。

连接中、清理尚未确认或断开后仍运行的命名会话都会阻止该项目修改目录或网络模式；暂停中的实例需先恢复，再检查和清理。控制服务重载可以重连原命名服务器；真实冷重启后先核对原 cgroup 和运行资源不存在，再保留原票据并登记退休，重新打开会话发行新 UUID，旧共享授权不复活。新连接会清理没有宿主连接归属的匿名终端，不会关闭其他活动连接或命名服务器。

“停止项目终端”先断开网页连接并保存停止状态，再关闭对应的整个 cgroup，包括后台、另建窗口和另建会话的后代；确认准确运行域停止后清理该次 socket 与回执，最后核销宿主票据。准备与资源清理使用同一运行锁，取消后仍在收尾的 root 准备进程不能在清理完成后写回旧资源。全项目停止也清理这些终端，再核销原私有网络。失败保留具体错误码、原票据和连接租约供重试。其他项目的会话不受此操作影响，标签和布局保留；刷新不会重建已停止会话。匿名普通终端断开时执行同样的全域清理。

管理员可向有该实例权限的只读账户共享一个运行中的会话。授权同时绑定项目和该次会话的随机唯一标识：修改活动项目、在其他项目建立同名会话，或停止后重建同名会话，都不会把旧授权转移到新会话。新会话需管理员重新共享。只读连接仍在服务端拒绝输入和尺寸调整；撤销或续签授权会关闭旧连接。旧版本未绑定项目或运行会话的授权可保留在目录中，但不能连接，需重新共享。

基础命令执行 API、SDK 和 CLI `exec` 的范围与取消规则见 [项目命令执行](project-execution.md)。不同项目的文件权限边界取决于原目录迁移后的属主、权限与 ACL。客户机 root 仍可修改这些设施，独立系统 SSH、cron、用户管理器及其他未迁移扩展仍有其他入口，覆盖范围见 [项目账号](project-identities.md) 与 [项目网络隔离](project-network-isolation.md)。旧 root tmux 会话不会自动认领为新账号终端，须先明确核查并关闭原会话及后代。

`npm run test:project-terminals:identity -- --run-new alpine` 创建独立的一次性 QEMU 客户机，编译实际原生启动器，验证真实交互 PTY、跨项目读取拒绝、命名终端与新增窗口归属、只读输入拒绝、全域停止与同名重建授权，以及普通输出管道不能启动终端帧。所有实际源码摘要、观察值、错误及完整 QEMU 关闭状态保存在新的验证文件中。`--run-owned alpine <测试目录>` 只接受该脚本已有的、已物理关闭的测试实例，使用新的开机和验证 UUID；旧失败记录不会覆盖。

`tests/project-terminals.test.ts` 和 `tests/project-run-scope.test.ts` 覆盖准备租约、重载、目录迁移门闩、失败清理重试、孤立匿名运行恢复和冷重启退休。旧 `test:project-terminals` HTTP/浏览器脚本仍包含 root tmux 假设，不代表此账号版本已完成跨发行版界面验收。
