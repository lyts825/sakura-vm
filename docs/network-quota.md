# 客户机出站带宽配额（部分实现）

在“能力中心 → 扩展能力 → 客户机出站带宽配额”中选择 `network-quota`，把 `mode` 设为 `status`、`apply` 或 `clear`。`egressKbps` 是指定客户机网卡的出站上限（64–1,000,000 Kbit/s），`burstKiB` 是突发缓存，`latencyMs` 是队列等待上限。也可先使用检查按钮读取当前网卡规则。

执行器使用客户机内的 Linux `tc` TBF 规则。运行中的客户机需要安装 `iproute2` 并允许配置网络队列。应用前先读取现有根规则；发现 netem、HTB 或其他非默认规则时拒绝覆盖。清除操作只删除 Sakura 使用的 `42:` TBF 根规则，不会删除不属于它的规则。客户机重启后内核规则消失，需要再次应用。

目前只限制该网卡的出站字节速率，尚未限制入站速率、并发连接数或请求速率，因此功能目录仍标为“部分实现”。`npm run test:network` 会在真实 Alpine/QEMU 客户机中应用规则、检查发送计数并清除规则。
