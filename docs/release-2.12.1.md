# 2.12.1 · 插件中心按用途整理

本次从 2.12.0 升级到 2.12.1，整理插件浏览、搜索和成员入口。目录保持 486 个插件、46 个整合包，默认选择仍为空，宿主插件 API 保持 5。

## 变更

插件中心默认展示整合包。常用核心、核心细分、环境与交付、工程验证、数据与建模、内容与设计、流程与扩展实验，以及实验与兼容分别分组。日常使用、开发工作台和运维与备份优先展开，其余组按需查看。搜索和用途筛选可以找到各组中的包，已选包继续显示选择状态。

包详情提供成员与依赖入口，可在单插件目录中查看指定包的完整范围，并返回整合包。单插件目录保留独立选择、运行状态筛选和异常处理入口。分类依据包的直接成员推导，共享依赖和完整兼容包不会把所有插件归入同一类。

日常使用包包含依赖共 5 个插件；与开发工作台合用为 18 个，再加运维与备份为 25 个。以上数量经过依赖去重，浏览和筛选不会自动选择任何包。现有插件数据、启停流程、必需依赖和可选配套规则保持不变。

README、插件架构和文档索引同步当前目录及版本，保留各次迭代的历史记录。发行文档清单加入本说明。

浏览器回归入口显式加载已有的 tsx，以便测试夹具读取 TypeScript 插件目录中的 JSON 导入。既有用例同步默认浏览方式，并继续核对共享依赖、失败反馈和窄屏布局。

## 验证与交付

486 个插件契约、46 包解析及分类覆盖检查通过。7 项选择、依赖、持久化和迁移回归通过；TypeScript、2,560 模块架构检查、前端及主服务端生产构建、繁体语言包同步通过。

8 个定向浏览器场景全部通过覆盖，包括默认三包、全部目录可发现、成员范围与返回、共享依赖保留、保存失败反馈、日夜主题和窄屏。390/320 像素页面无横向溢出，桌面及手机截图已目视核对。首次收集失败和旧搜索断言失败的记录保留，修正后仅复验受影响项。

本轮未改变业务算法和原生执行，未重复真实 VM、完整发行安装或外部服务验收。实现提交、服务契约基线和本地版本标签记录在项目状态中。

## 兼容与范围

本次调整展示组织及导航，不删除业务插件，不修改公开接口或持久选择格式。未启用的领域插件继续按需加载；既有实验性标记保持不变。源码交付不代表已经推送、发布或部署。
