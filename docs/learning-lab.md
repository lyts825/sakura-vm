# 交互式实验

## 用途与插件

`learning-lab` 包含 11 个插件：课程、课件、课节、环境、步骤、检查、会话、进度、评估、交接和工作台。它为本地所有者提供文件、配置和受限请求练习。包保持实验性，默认不启用。

完成记录属于实际登录主体。工具检查、人工自评和导入声明分别保存；记录不作为考试成绩或认证证书。

## 开始练习

1. 启用插件包，按插件页提示重启。
2. 准备包含 Python 3 的 Alpine x86_64 镜像，通过原镜像资产入口导入。执行不会自动安装依赖。
3. 按[容量说明](suite-capacity.md)配置宿主预算。每次 VM 至少预留 8 GiB 虚拟磁盘，另计镜像、输入、输出和恢复额度；默认 8 GiB 总额不足以执行。
4. 选择“文件与目录”“配置修复”或“请求与响应”。创建示例只保存课程、文件和初始环境定义。
5. 选择封存课程、对应环境、步骤和检查，预览并批准一次新尝试。
6. 阅读课节，在允许的文本或 JSON 字段中修改内容。逐步预览并批准，查看实际文件快照、反馈和原资源清理结果。
7. 生成进度和自学评估，填写自评后封存。材料获得导出许可后，可交接报告与完整引用图。

CLI 入口为 `npm run learning -- help`。调用形式为 `learning <领域> <动作> <输入.json>`。HTTP 入口使用 `/api/learning-<领域>/<动作>`；方法和字段以生成帮助及契约为准。

## 编写课程

先创建草稿课程，再上传 `sakura-learning-files/1` 文件材料，并固定镜像和课件。每个课节包含静态讲解、目标、唯一键和先修课。封存课程时核对先修顺序，拒绝重复课节、未知前置课和循环关系。

步骤只能使用固定动作：列举文件、读取文件、写入文本、启动或停止演示状态、发送受限请求和运行检查。课程固定路径、方法及端点。作者可以允许学习者编辑写入内容或请求体，不能开放任意命令、脚本或外部地址。

检查覆盖文件是否存在、文本相等或包含、JSON 对象相等和演示服务状态码。实际检查在工具会话中执行；保存检查定义不会产生通过记录。每步重查课程的全部选定规则，后续修改破坏既有结果时会撤回相应完成状态。

课程升级使用新的课程对象和修订。旧尝试固定在原课程上，旧进度不会自动转移到新版。当前正文为静态纯文本，课件只支持固定文本文件。

## 环境与恢复

环境准备保存输入定义。实际执行从会话批准开始：每一步都从上一份实际快照新建隔离 VM，执行一个固定动作，捕获文件，再停止并删除该 VM。步骤之间不保留物理终端或服务。

演示服务状态是课程数据。请求步骤会短暂启动真实本机 HTTP 服务，处理 `/state` 或 `/echo`，然后关闭。启动和停止动作也用实际请求核对 200 或 503。

会话空闲 15 分钟后，在下一次查询或动作准入时转为暂停；绝对期限为 1 小时。空闲期间没有遗留 VM。正在执行的步骤另有 180 秒截止和原身份看门狗。暂停后可在期限内恢复；到期后须建立新尝试。

检查点只来自已经确认清理的实际快照。恢复创建新的环境定义，重新批准后产生新会话和新 VM，不复制旧完成状态。中断后的查询只更新原记录，核销只操作原资源，重复批准返回原意图。

## 实施预算

每门课程最多 12 个课节，合计 30 个步骤和 30 条检查。每次尝试最多执行 30 个学习动作，另有一次初始检查。文件最多 100 个，单文本 64 KiB，文件总内容 2 MiB；路径最多 8 层。实际 JSON 传输还受 8 MiB 帧限制。

学习 VM 使用 1 vCPU 和 1 GiB 内存。空间预算为 64 GiB，仍受宿主共同额度约束。每空间最多保留 5 个检查点。进度聚合最多 100 次尝试，单次页面最多显示 20 条领域记录；交接包上限为 16 MiB。达到元数据或图预算时拒绝新增，保留已有结果。

## 交接与清理

导出只接受封存的自学评估。所有被引用会话必须确认清理，原材料必须有当前读取和导出许可。每次下载重查许可。导出移除本机执行身份，保留无执行权限的来源声明。

`learning verify <交接包>` 在完整安装包中以纯 Node 离线核验封套、字节、文件摘要和声明关联。结果始终标记 `toolExecutionVerified=false` 和 `certification=false`。接收进入新的隔离空间，导入的通过记录不能用于本机先修条件或完成判定。

清理需先预览保护引用。报告、课程和检查点仍在引用的对象不能删除。最后一个会话修订移除后，才释放对应本体输入和输出；资源未确认清理时保留预算和恢复入口。

## 验证结论

三个课程模板通过实际服务链的 61 项检查，覆盖真实文件步骤、失败反馈、先修课、检查点恢复和自学报告。页面交互另有 12 项合成协议检查。学习预览补偿、取消立即同步和逐次执行材料清理通过 30 项定向协议检查；这组检查使用执行端口替身，不计作真实 VM 证据。
