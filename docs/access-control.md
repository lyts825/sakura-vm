# 多用户与只读分享

Sakura 默认沿用仅本机访问的控制令牌。管理员可在“系统设置 → 账户与只读分享”启用账户模式并设置至少 12 字符的 `owner` 密码。启用后原控制令牌立即失效，`/api/bootstrap` 不再发放管理员令牌；刷新页面会进入账户登录。账户模式目前只监听 `127.0.0.1`，适合同一台主机上的不同本地用户，不提供外网公开入口。

`owner` 可管理全部现有功能，并为选定实例创建最多 40 个只读账户。每个只读账户有独立密码、5 分钟至 30 天的账户有效期，登录会话最多持续一小时；管理员会话最多八小时。只读页面显示获授权实例的名称、状态和基本资源；桌面插件启用且客户机桌面就绪时，还可打开只读桌面视图。服务端只允许该实例的桌面查看通道，过滤 RFB 键盘、鼠标、剪贴板、桌面调整及未知控制消息。其他控制 API、日志、终端、下载签发和 WebSocket 均被拒绝。删除账户会立即撤销其会话及活动桌面连接；服务重启和控制面锁定也会使全部账户会话失效。

账户密码使用加盐 scrypt 保存，本机账户文件不保存明文密码或会话令牌。连续五次错误登录触发一分钟冷却。审计链记录登录请求的结果，并为携带账户令牌的写请求记录账户 ID；不记录密码和请求体。`owner` 可通过 `POST /api/access/password` 提交旧密码与 `newPassword` 轮换密码，此操作撤销全部现有会话。

生成的 JavaScript SDK 在账户模式下先调用 `await client.login('owner', password)`；随后可以调用已授权的 API，结束时调用 `await client.logout()`。旧的 `authenticate()`/`/api/bootstrap` 只用于未启用账户模式的本机控制令牌。只读账户的 SDK 调用同样受服务端限制，只能读取 `/api/access/view`；桌面视图使用专门的 `/ws/:vmId/desktop-view` 通道。

当前只有内置 `owner` 与限定实例的 `viewer` 两种角色。自定义 RBAC、项目级成员权限、JIT 授权、双人审批和单点登录仍在未完成清单中；不能把只读账户当作这些功能的替代。

## 通行密钥登录

账户模式下，`owner` 和 `viewer` 都可在 `http://localhost:<端口>` 的账户设置中用当前密码登记最多 10 把通行密钥。登记后登录页可使用通行密钥免密登录；密钥可在同一页面撤销，撤销会使由该密钥建立的会话立即失效。浏览器、系统或安全密钥必须支持驻留凭证与用户验证。由于 WebAuthn 的 RP ID 限制，通行密钥只在 `localhost` 页面可用，`127.0.0.1` 页面提供跳转链接。服务仅保存公钥、凭证 ID、计数器和显示名称，不保存私钥；注册与登录挑战五分钟过期且只能使用一次。账户、控制面锁定、重启与账户有效期限制仍适用。更换管理员密码不会自动删除已登记的通行密钥，需要撤销时请在账户设置中逐把操作。
