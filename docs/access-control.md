# 多用户、只读分享与项目成员

Sakura 默认沿用仅本机访问的控制令牌。管理员可在“系统设置 → 账户与只读分享”启用账户模式并设置至少 12 字符的 `owner` 密码。启用后原控制令牌立即失效，`/api/bootstrap` 不再发放管理员令牌；刷新页面会进入账户登录。账户模式目前只监听 `127.0.0.1`，适合同一台主机上的不同本地用户，不提供外网公开入口。

`owner` 可管理全部现有功能，并创建合计最多 40 个只读账户或项目成员账户。每个只读账户有独立密码、5 分钟至 30 天的账户有效期，登录会话最多持续一小时；管理员会话最多八小时。只读页面显示获授权实例的名称、状态和基本资源；桌面插件启用且客户机桌面就绪时，还可打开只读桌面视图。服务端只允许该实例的桌面查看通道，过滤 RFB 键盘、鼠标、剪贴板、桌面调整及未知控制消息。未单独授权的终端、其他控制 API、日志、下载签发和 WebSocket 均被拒绝。删除账户会立即撤销其会话及活动桌面连接；服务重启和控制面锁定也会使全部账户会话失效。

账户密码使用加盐 scrypt 保存，本机账户文件不保存明文密码或会话令牌。连续五次错误登录触发一分钟冷却。审计链记录登录请求的结果，并为携带账户令牌的写请求记录账户 ID；不记录密码和请求体。`owner` 可通过 `POST /api/access/password` 提交旧密码与 `newPassword` 轮换密码，此操作撤销全部现有会话。

生成的 JavaScript SDK 在账户模式下先调用 `await client.login('owner', password)`；随后可以调用已授权的 API，结束时调用 `await client.logout()`。旧的 `authenticate()`/`/api/bootstrap` 只用于未启用账户模式的本机控制令牌。只读账户的 SDK 调用同样受服务端限制：只能读取 `/api/access/view` 和自己的终端共享授权，并管理自己的通行密钥与会话交接；桌面和终端查看使用各自独立的 WebSocket 通道。

当前账户类型为 `owner`、限定实例的 `viewer` 和默认无权访问的 `member`。项目成员可由管理员按项目分配自定义角色；单点登录仍在未完成清单中。

## 项目成员与自定义角色

先启用“项目工作区”插件并重启 Sakura，再启用账户模式。管理员在“系统设置 → 账户与只读分享 → 项目成员与权限”创建成员账户，选择实例和项目，定义该项目的角色，再给成员选择角色并保存。角色 ID 在同一项目内唯一，可配置 `read`、`write`、`execute`、`approve` 权限；除单纯读取外的角色必须包含读取。未分配角色的成员无法访问任何项目，分配或撤销后无需重新登录即生效。成员会话最多一小时；删除成员即撤销会话与项目授权。成员可在登录后的独立页面查看授权项目、读取或编辑项目配置，并在具有执行权限时提交初始化、启动和停止任务。

成员的项目请求必须显式带 `?project=<项目 ID>`，避免当前选中项目变化时误操作。服务端按账户、实例、项目及操作权限逐次校验，只开放项目配置 `GET/PUT/POST`、项目运行状态 `GET`、项目文件搜索 `GET`、Git 工作台 `GET/POST` 和服务健康 `GET`；这些接口仍受对应插件启用状态限制。角色的 `read` 允许读取，`write` 允许保存项目配置但不能更改项目目录，`execute` 允许运行项目操作与 Git 操作。授权时项目目录不能与同一实例中的其他项目重叠；若管理员后来改成重叠目录，成员请求会被拒绝，直到目录重新分离。其他实例 API、全局 API、任意文件路径 API、Secrets、网络、终端、桌面、下载及 WebSocket 均不授予成员。项目权限仅保护 Sakura 控制面；拥有宿主机文件权限或客户机 SSH 凭证的用户仍可在控制面之外访问数据。拥有执行权限的成员可通过项目脚本在客户机中运行命令，这不是客户机操作系统级别的租户隔离。

管理员 API：`POST /api/access/members` 创建成员，`DELETE /api/access/members/{id}` 删除；`GET/PUT /api/access/project-permissions?vmId=<实例 ID>&projectId=<项目 ID>` 查看或整体替换角色与授权。成员 API：`GET /api/access/projects` 列出自身项目。角色和授权保存在本机账户目录旁，服务重启后保留；会话令牌不落盘。管理员仍拥有全部项目权限，无需显式分配角色。

## 签名项目策略包

管理员可在同一页导出当前项目的完整角色、成员授权和双人审批设置。Sakura 用本机 Ed25519 密钥签名 JSON 策略包；私钥只保存在本机数据目录，导出包和 API 只包含公钥。接收端先验证签名，再显示来源、签名者、当前策略和拟应用策略。外部签名者的公钥须由管理员显式加入信任列表，撤销信任后其策略包立即不能应用；本机公钥不可撤销。签名使用独立的项目策略域，与实例包签名不能互换。

应用时管理员显式选择目标实例和项目，并提交预览所得的目标版本。服务在项目权限写入锁内重新验签、检查当前信任状态和目标版本，随后校验角色、成员账户及项目目录隔离条件并整体替换策略。每次权限变更都会增加修订号，即使内容后来恢复，旧预览也会失效。跨主机导入时，包中的成员账户 ID 必须在目标主机存在且为项目成员；不能自动映射用户。此签名证明策略包内容和签名者，不能阻止拥有本机管理员权限的人直接修改数据文件。接口为 `GET/POST /api/access/policy-bundles/keys`、`POST /api/access/policy-bundles/export`、`POST /api/access/policy-bundles/preview` 和 `POST /api/access/policy-bundles/apply`，均限 `owner` 使用。

## 双人变更审批

管理员可在项目权限中开启“项目配置变更需要第二位账户审批”。开启后，该项目的直接 `PUT /api/vms/{vmId}/project` 对管理员和成员都返回 409。申请人提交变更摘要、完整项目配置与当前版本；审批人必须是另一个账户，可以是管理员，或具有该项目 `approve` 权限的成员。审批人可查看完整配置并批准或拒绝；申请人获批准后在 24 小时内一次性应用。服务在保存时再次核对项目版本和目录，期间有其他修改则拒绝应用并记录失败；提交人不能审批自己的请求，审批人失效或权限被撤销后也不能应用旧批准。进程在申请已领取但未确定写入结果时不会自动重试，以免重复应用。

成员页面可填写摘要并提交自己有 `write` 权限项目的配置；管理员可在项目权限设置中提交自己的完整配置变更。两者都可在“项目变更审批”中查看可见请求、审阅配置并执行有权操作。接口分别为 `GET/POST /api/access/changes`、`POST /api/access/changes/{id}/decision` 和 `POST /api/access/changes/{id}/apply`。申请和审批记录落盘，审计链另记录对应写请求的账户 ID。此审批保护的是 Sakura 的项目配置写入，不包括 Git 推送、项目脚本运行、实例删除或宿主机上的直接文件操作。管理员仍可修改或关闭审批策略；它不是防范拥有本机管理员权限者的独立信任边界。

## 通行密钥登录

项目成员也可按同一流程登记和使用自己的通行密钥，权限仍由项目角色决定。

账户模式下，`owner` 和 `viewer` 都可在 `http://localhost:<端口>` 的账户设置中用当前密码登记最多 10 把通行密钥。登记后登录页可使用通行密钥免密登录；密钥可在同一页面撤销，撤销会使由该密钥建立的会话立即失效。浏览器、系统或安全密钥必须支持驻留凭证与用户验证。由于 WebAuthn 的 RP ID 限制，通行密钥只在 `localhost` 页面可用，`127.0.0.1` 页面提供跳转链接。服务仅保存公钥、凭证 ID、计数器和显示名称，不保存私钥；注册与登录挑战五分钟过期且只能使用一次。账户、控制面锁定、重启与账户有效期限制仍适用。更换管理员密码不会自动删除已登记的通行密钥，需要撤销时请在账户设置中逐把操作。

Windows 管理员还可勾选本机平台认证器选项登记 Windows Hello 等通行密钥，并在控制面锁定页直接解锁；范围和验证见 [Windows Hello 解锁](hello-unlock.md)。

## 会话交接

在账户设置中输入当前账户密码并生成交接码，然后在同一台主机的另一个 Sakura 登录页输入该码。交接码随机生成、只显示一次、两分钟过期且只能接收一次；生成新码会取消当前会话此前的码，也可手动取消。接收成功后原会话和它的 WebSocket 立即失效，新会话继承原账户权限、原会话到期时间及通行密钥撤销关系，不会延长访问期限。控制面锁定、账户撤销、密码轮换、服务重启或原会话退出都会使待接收的码失效。交接码不写入磁盘，请只交给预期的接收者。

## 共享终端

先启用“可恢复终端会话”插件并重启服务，在客户机安装 `tmux`，启动实例并打开要共享的终端标签。管理员可在该标签下方选定已有的、对该实例有权限的只读账户，设置 1–480 分钟有效期并共享。对方登录后可在实例列表打开“只读查看终端”，实时查看同一 tmux 会话。服务端按账户、实例、会话和有效期校验独立的 `/ws/:vmId/terminal-view` 通道，拒绝所有客户端输入与尺寸消息；tmux 客户端自身也以只读模式附着。撤销授权会断开活动连接，账户删除、控制面锁定和实例应急锁定同样会阻断查看。该授权不赋予普通终端、命令执行或其他控制接口权限；终端内容可能含敏感信息，管理员应只共享预期会话。
