# 客户机网络延迟与丢包模拟

在能力中心选择“延迟丢包模拟”，填写 Linux 网卡名（默认 `eth0`）、延迟、抖动和丢包百分比。`inspect` 读取当前 `tc` 队列规则；`apply` 在所选网卡的根队列设置 `netem`；`clear` 仅在当前根规则为 `netem` 时删除该规则。检查操作只预览参数和现状，不修改客户机。操作需要客户机运行且安装 `tc`（通常由 `iproute2` 提供）。

延迟范围为 0–2000 毫秒，抖动为 0–500 毫秒且不能超过延迟，丢包率为 0–25%；应用时至少需要一项非零设置。网卡名和数值经校验后才进入客户机命令。执行后会重新读取队列规则，只有内核显示预期状态才报告成功。该规则作用于整个指定网卡，客户机重启后不会自动恢复；需要再次应用。`clear` 会删除客户机当前的根 `netem` 规则，不会删除其他类型的根规则。

单元测试覆盖无写入预览、应用、清除、无效参数和缺少工具；`npm run test:network` 在真实 Alpine/QEMU 客户机的环回网卡上验证内核规则设置与清理。
