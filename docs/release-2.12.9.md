# 2.12.9 · 插件解析与操作路由性能优化

本次从 2.12.8 升级到 2.12.9，日期为 2026-10-29。范围为插件中心的重复目录校验和后端操作路径匹配。状态：已完成。

## 改进

插件中心为每份服务端状态复制并校验一次私有目录快照，再复用解析器计算包成员与变更预览。每次选择仍执行输入校验；收到新状态时重建解析器，不保留历史状态。原严格解析入口继续逐次校验完整目录。

后端按路径段数和末段建立固定声明索引，预编译变量段，减少每次请求的展开、扫描与解析。索引保留原路径优先级、同级声明顺序、参数解码和方法匹配规则。授权、启用状态、取消和执行结果不进入缓存。

## 性能与正确性

基线为 2.12.8 的 `7b8c8fc8`，环境为 Windows x64。以下是本机结果，不代表所有硬件或完整业务请求的加速幅度。

| 测量范围 | 改动前 | 改动后 | 条件 |
| --- | --- | --- | --- |
| 插件中心组件挂载到完整目录就绪 | 3,993.9 ms | 228.9 ms | Chromium 153，1440 × 1000，每版预热 1 次、交替 5 对样本的中位数。 |
| 新状态的 92 次选择推导 | 5,021～5,089 ms | 87～104 ms | Node 24.15，3 组选择场景；包含新快照复制和校验，不含 DOM 与网络。 |
| 插件路由归属查找 | 3.37～4.33 ms | 0.001～0.006 ms | 3 条代表路径，每条各取 5 轮单次耗时中位数。 |
| 网关路径与方法解析 | 3.08～3.96 ms | 0.0006～0.0054 ms | 同上，保留成功及 404、405 行为。 |

浏览器使用真实组件、生产 React 和完整的 486 插件、46 包目录，接口为受控实现。计时终点为 46 个包的 DOM 就绪后两次动画帧回调，组件首次呈现耗时减少约 94%。测量与后端基准错开执行。完整包卡片和预览、486 个插件名称、搜索、展开、成员显示、一次选择请求、选择更新及新目录刷新均与基线一致，未出现浏览器异常。此结果是独立组件测量，不是完整应用端到端基准。

后端函数基准预热 30 次，旧算法每轮运行 100 次，新算法每轮运行 5,000 次。静态索引分别覆盖 9,168 条插件路由及 9,322 条网关声明，后者包含 9,316 条 HTTP 和 6 条 WebSocket 声明。两个索引构造各约 5.6、5.8 ms，辅助结构保留堆各约 2.10、2.17 MB，不含原始声明；大小由目录决定，不随请求路径增长。

9,096 个路由归属场景、9,626 个网关场景和 322 个匹配器场景与旧实现一致，覆盖静态路径优先、同级顺序、方法不匹配时拒绝回退、非法编码、保留的任务聚合入口和独立参数对象。现有网关 14 项、插件 21 项测试全部通过。

前端 276 次选择推导与旧实现相同，11 类无效目录、选择校验、嵌套包、迁移及输入输出突变隔离通过。连续更换 30 份状态后，受控 GC 检查确认旧解析器均可回收；这不替代整个应用的长期内存测试。

完整生产构建及 TypeScript 检查通过。架构检查覆盖 2,569 个模块；605 个服务声明、486 个插件、46 个包、9,316 条 HTTP 和 6 条 WebSocket 契约检查通过。繁体资源的 6,930 条短语与 116 个动态片段同步检查通过。

插件中心 7 项既有浏览器回归全部通过，用时 39.6 秒，无需修改既有用例。编译版生产验收通过，覆盖 7 组插件组合、生产内容安全策略下的页面与媒体、离线只读状态、跨标签锁定、本地 Webhook 与助手协议，以及不依赖源码目录的网络入口和独立 worker。

发行检查通过，覆盖 1,011 个服务模块。首屏主 JavaScript 为 632,175 字节，初始静态资源为 1,377,927 字节，均在原 950,000 和 1,650,000 字节预算内。版本一致性与 258 个本地文档链接检查通过。

基准脚本、报告和日志保留在已忽略的 `artifacts/performance-2.12.9/`，不纳入 Git。初期夹具定位与基准请求方法错误已修正，相关业务代码未因此改写，最终对比与回归通过。未运行全量测试、真实 VM 或其他平台验收；没有执行长期整机负载测试。
