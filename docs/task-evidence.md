# 任务证据与处理

在任务中心展开任务，点击“查看证据与处理”，可查看任务时间线、发起请求的回执，以及相关资源的恢复记录。此功能随本体提供，不依赖额外插件；启用维护插件后，还可跳转到该实例的诊断页面。

新请求产生的任务保存回执 ID。回执分别记录业务处理、响应校验、审计与交付状态；请求成功可能只代表任务已接收，任务是否完成仍以后台任务状态为准。后台调度和旧版任务可能没有回执关联。回执仍遵守原有会话与账号权限，无法读取时会显示错误，不推断操作没有发生。

恢复目录使用任务 ID、请求关联 ID 或资源租约 ID 确认关联；已知实例或项目身份冲突时不关联。同实例但缺少确切身份的记录单列为参考，不能视为本任务的故障原因。页面优先显示确切关联，最多显示 20 条；完整目录可在插件中心查看。没有匹配记录不代表资源已经释放。

恢复按钮仅使用资源所属服务已公开的动作，提交当前记录摘要，由原服务再次验证并执行。恢复目录降级或记录不可用时禁用操作。处理后刷新权威状态，不自动重跑原任务，也不代替所属服务释放资源。原任务日志仍显示在任务详情中。

定向验证覆盖回执关联的持久化、并发请求隔离、独立后台任务解除关联、回执访问权限、请求成功但任务仍运行，以及恢复记录的身份匹配与冲突排除。验证使用隔离目录，不操作用户实例。
