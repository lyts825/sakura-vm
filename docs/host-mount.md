# 宿主目录挂载

在“能力中心 → 资源 → 宿主目录挂载”填写一个已存在的宿主绝对目录，选择只读或可写，启用并保存。运行中的实例立即挂载；之后每次实例启动会自动恢复。客户机路径固定为 `/mnt/sakura-host`。也可使用 `GET /api/vms/:vmId/host-mount` 查看状态，或通过 `POST` 发送 `configure`、`mount`、`unmount` 操作。

该功能在宿主的 `127.0.0.1` 启动仅接受 SFTP 的临时 SSH 服务。客户机经 QEMU 用户网络的 `10.0.2.2` 连接，使用每次挂载生成的密钥和固定的服务器公钥。共享服务只映射选定的目录；拒绝 `..`、符号链接、Windows 目录联接和特殊设备路径。只读设置由宿主 SFTP 处理器强制执行。Sakura 数据目录及其上级目录不能作为共享根目录。卸载或停用会关闭相应宿主服务。

首次使用会在客户机安装 SSHFS，并加载 FUSE 内核模块。Alpine 使用 `apk`，Debian/Ubuntu 使用 `apt`，因此需要客户机软件源可用。挂载由客户机 root 用户创建；客户机的其他用户默认不能访问 FUSE 挂载。服务仅支持普通文件和目录，不导出符号链接，也不支持所有 POSIX 文件元数据语义。此实现是 SSHFS 挂载，**不是** Virtio-FS；目录在宿主本机权限下运行，没有独立操作系统沙箱，不能用于隔离不受信任的宿主目录写入者。

`npm run test:host-mount` 在真实 QEMU/Alpine 中验证宿主文件读取、客户机写回、只读拒绝、重启自动恢复和卸载。`tests/host-mount-sftp.test.ts` 直接验证 SFTP 根目录边界、符号链接拒绝和只读策略。
