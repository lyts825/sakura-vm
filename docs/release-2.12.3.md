# 2.12.3 · 工作空间界面优化

本次从 2.12.2 升级到 2.12.3，优化首页信息层级、窄屏工具栏和键盘导航。日期为 2026-10-28。目录保持 486 个插件、46 个整合包，宿主插件 API 保持 5。

## 变更

已有实例时，首页使用紧凑欢迎区和统计条，缩短到实例操作区的距离。樱花插图、日夜主题和创建入口继续保留；首次使用仍显示完整欢迎区。

统计卡和实例面板取消悬浮位移与大阴影，静态信息保持稳定。按钮继续提供悬浮、选中和焦点反馈。

顶部工具栏按可用宽度换行，保留主题、命令面板和账户等已启用操作。键盘用户可通过“跳转到主要内容”跳过导航，直接进入当前页面。

“已暂停”筛选没有结果时，显示“暂时没有已暂停的空间”，避免误报为已停止状态。

## 验证与交付

类型检查、完整生产构建、2,567 个模块的架构检查和繁体资源同步通过。486 个插件、46 个整合包、605 个服务声明，以及 HTTP、WebSocket 契约检查通过。

14 个本地界面场景通过，覆盖日夜主题的 1440、768、390、320 像素宽度、首次使用、键盘跳转、搜索筛选、实例切换、主题与动画开关、创建入口，以及长账户名、命令面板和锁定失败提示。3 项现有浏览器回归通过，覆盖插件导航、命令面板和创建发行版。最终图层调整后，相关按钮与工具栏再次验证通过。

发行检查通过，首屏 JS 为 624,498 字节，低于 950,000 字节预算。验证在 Windows x64 上使用受控 API 和 Chromium 完成；没有重跑全量测试、真实 VM 或其他平台验收。

本地交付由 `v2.12.3` 标签定位，记录见 [项目状态](../PROJECT_STATUS.md)。没有推送、发布或部署。
