# 网页应用剪贴板策略

系统设置 → 剪贴板敏感检测 → 按应用剪贴板策略，可为“工作台其他页面”“终端”“文件浏览与编辑”“远程桌面”设置复制/剪切、粘贴、剪贴板文件与图片、敏感文本检查和文本大小上限。默认允许双向传递，文本默认上限 1 MiB。可选择一个实例并启用单独设置；移除覆盖后重新继承对应应用的默认策略。全局敏感检测与应用检测取并集，应用不能关闭已启用的全局检测。

这是 Sakura 网页入口的策略，**不管理 Windows/Linux 独立应用进程的系统剪贴板权限**。因此目录中的“按应用剪贴板策略”仍标为部分实现；后续需要宿主与客户机代理才能提供操作系统应用粒度的能力。控制用户仍可修改本浏览器设置，不将其称为不可绕过的 DLP 或系统隔离边界。

复制和剪切在捕获阶段检查选中内容，在冒泡阶段再次检查编辑器写入的纯文本及 HTML。禁止复制时先阻止剪切默认动作，避免删去原文。粘贴在到达终端、编辑器或文件上传处理器之前被检查；文件策略实际阻止剪贴板图片和文件上传。显式上传、下载、拖放、人工键入及程序执行不属于剪贴板操作。二进制文件与图片内容没有敏感信息扫描，文本模式也不能识别所有秘密。

远程桌面在接收 noVNC 剪贴板事件、发送到 Linux 和调用浏览器剪贴板写入时使用同一策略。收紧规则会清除页面中不再允许显示的文本；如果 noVNC 缓存了不再允许发送的内容，会重连桌面传输以释放缓存，不发送空字符串去覆盖客户机剪贴板。客户机应用继续运行。该策略检查桥接事件，不阻止原始 VNC 流已经把报文交给客户端库。

文本上限按 UTF-8 字节计数。终端粘贴还受 16 KiB 上限约束，保证带括号粘贴边界的输入不会超过控制服务单次消息限制。仅检查用户触发的剪贴板事件和桌面桥接事件，不轮询宿主剪贴板。

策略仅存储在当前浏览器的 `sakura-clipboard-policies`，只包含应用标识、实例标识和权限，不保存剪贴板内容。最多 64 个实例覆盖，可随时恢复全部默认设置。同源标签页即时接收设置变化；保存失败时保持当前标签页的内存策略并明确提示。损坏或超大配置默认阻止剪贴板传递，设置页允许重置恢复。

验证包含纯规则测试、真实 xterm 输入拦截、实例覆盖、持久化与损坏恢复、文件粘贴阻断和显式上传，以及真实 noVNC 客户端通过本机 WebSocket 接收/发送 RFB 剪贴板报文、跨标签策略收紧和缓存重连。没有据此宣称已实现系统进程级权限。
