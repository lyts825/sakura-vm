# 插件功能灰度

在“系统设置 → 插件功能灰度”选择插件，设置启用状态、放行比例（0–100%）和灰度版本。系统为本机保存稳定的随机标识，并根据标识、插件 ID 和灰度版本计算固定分桶。预览会显示当前主机是否命中；更改比例时同一版本保持分桶不变，更改版本会重新分桶。

保存策略后重启 Sakura 服务。启动时，插件中心已选择的插件只有在命中灰度策略后才会激活；未配置策略时保持插件中心原有行为。0% 或停用策略会跳过插件，100% 且启用会放行。依赖插件未激活时，依赖它的插件仍按原有依赖规则跳过。插件中心会显示灰度跳过的原因。运行中的插件不会在保存策略时突然卸载，正在执行的任务也不会被灰度变更中断。

灰度策略使用独立于插件选择的持久文件，并通过修订号拒绝旧页面覆盖新配置。删除策略会恢复该插件默认的启动选择，同样在重启后生效。本功能控制本机插件的启动，不控制未由插件提供的核心 API，也不把单台主机的比例当作当前运行流量百分比。

本机 API：`GET /api/feature-rollouts` 查看策略、分桶和当前激活状态；`POST /api/feature-rollouts` 接受 `preview`、`save`、`remove`。接口受控制面会话及本机凭证保护；请求结构已纳入 OpenAPI 和生成的 SDK。
