# Git 工作台的项目账号

Git 面板及 CLI 的状态、差异、冲突检查、暂存、提交、分支和 HTTPS 远程操作使用原项目的持久 UID/GID、独立 home、目录与网络。原生启动器固定目录描述符；命令不重新按路径切换目录。项目环境及命令经有界保护帧降权执行，管理员参数不包含正文或私密配置。

每次操作在读取配置前固定项目 ID 与客户机 live 身份，配置复制保留非枚举项目标识。准备租约核对原配置、项目及运行身份，环境只解析这份配置一次；完整状态读取、嵌套冲突检查或后台任务共用租约。异步步骤及结果返回前再次核对，配置或运行身份改变就停止后续步骤，不转向新项目。每条命令有独立完整任务域，原全域和账号票据清理确认后才释放准备租约；清理失败的 503、错误码和全部原因继续保留。

Git 使用项目账号 home 中的 `.gitconfig`，关闭系统配置、hooks 和 fsmonitor，清除可改变 Git 目录、对象目录、可执行文件、模板及配置注入的环境变量。仓库配置在项目 UID 下读取。保留原 NUL 状态解析、重命名、提交前密钥扫描、分支及冲突选择行为；原始内容完成解析和版本摘要计算后才对显示结果脱敏。

远程操作继续只接受无内嵌凭据的 HTTPS 地址，并保持非交互策略。fetch 不修改工作区；pull 只快进，push 不强制或镜像推送。私有项目在原私有网络内执行，无法访问远程时显示失败。网络命令时限 120 秒，其他 Git 命令 30 秒，冲突路径探测 10 秒。已经成功的步骤可能改变仓库，后续核对失败不会自动撤销或重试。

冲突编辑器仍使用现有管理员文件服务读取和上传所选文本，保留 1 MiB UTF-8 上限、文件历史、expectedVersion 检查及 UID/GID/mode；这些文件操作固定原目录和租约，并在前后复核运行身份。它们不执行仓库代码，但仍属于管理员 SFTP 范围，不能视为新的项目专属文件权限边界。既有 root 目录需要明确核对并应用 [目录迁移](project-directory-migration.md)，工作台不自动创建或改属主。

完整 stdout/stderr 合计最多 1 MiB，原状态和索引数据不截断；显示差异保留原 200000 字符上限。正文与环境合计受原生 64 KiB 限制，大批路径或环境超限返回 413 / `PROJECT_IDENTITY_PAYLOAD_INVALID`，该条命令不执行，不拆成部分暂存。冲突编辑器文本沿用文件上传通道。

当前正式验证包括 19 项本机真实 Git 回归及 17 项项目身份模型，共 36 项通过，完整类型检查通过。本机 Git 使用受控任务适配器，不能替代 Linux UID 降权、真实远程或客户机验证；本次尚未运行新的 Git 工作台客户机联测。
