# 事件自动化规则

在“系统设置 → 事件自动化规则”创建规则。规则匹配任务完成或新告警事件，可按实例、项目、标签、任务状态和告警类型筛选。动作只作用于事件所属实例：启动、正常停止、暂停或恢复。规则默认停用且仅预览；勾选“启用规则”并明确选择“实际执行实例操作”后，后续匹配事件才会触发动作。保存或修改规则会从该时刻开始观察事件，不回放旧事件。

规则为经服务端校验的声明式结构，最多 24 条；每条至少选择一种事件类型。冷却时间为 60 秒至 24 小时，同一规则每天最多尝试 25 次实际操作。每个规则版本与事件组合只处理一次，去重记录持久保存；最近 300 条执行记录包含预览、跳过、待完成、成功和失败。规则编辑有版本校验，旧页面不能覆盖新配置。预览按钮只展示最近匹配的事件和按当前配置可能执行的动作。

事件元数据来自任务记录和告警，不包含命令输出、日志或密钥。动作执行前重新检查规则版本、实例存在性、实例应急锁定和数据目录迁移。服务重启后不会自动重试已登记为待完成的动作，因为上一次动作可能已经生效；需要人工核对实例与记录。正常停止会等待客户机关闭；规则不会执行任意命令，也不会操作事件之外的实例。

本机 API：`GET /api/automation-rules` 读取规则与记录；`POST /api/automation-rules` 接受 `save`、`remove` 或 `preview` 操作。接口要求控制面会话和本机凭证，Schema 可从 API 说明下载。
