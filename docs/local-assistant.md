# 本地 AI 编程助手与命令规划

系统设置 → 打开本地助手。先在本机运行 Ollama 并下载适合机器资源的本地 GGUF 模型，勾选启用连接、保存根地址，再读取模型列表、选择名称并保存。默认连接关闭、地址为 `http://127.0.0.1:11434`，Sakura 不会安装模型运行时或下载权重。

接入使用官方 [模型列表](https://docs.ollama.com/api/tags)、[聊天接口](https://docs.ollama.com/api/chat)和[结构化输出](https://docs.ollama.com/capabilities/structured-outputs)协议。地址仅允许本机 HTTP 根源，不跟随重定向。列表过滤远程声明及 cloud 名称；每次生成先读取 `/api/show`，要求 GGUF 和本地 model_info，拒绝 remote_host/remote_model，检查通过后才发送上下文。模型元数据字段参考 [Ollama API 定义](https://github.com/ollama/ollama/blob/main/api/types.go)。

本地地址仍以用户配置的模型服务为信任边界。请按 [Ollama 仅本地模式说明](https://docs.ollama.com/faq#how-do-i-disable-ollama-cloud-features)设置 `OLLAMA_NO_CLOUD=1` 并重启模型服务，阻止其使用云功能；Sakura 不修改该服务的环境或日志设置。模型列表为空或服务未运行时会明确提示，不能把接口配置当作已经运行模型。

## 使用流程

选择编程问答、解释代码、测试建议、修复建议或自然语言命令规划，填写问题及需要提供的代码。输入仅来自此面板，不自动读取实例文件、日志或配置。点击预览后检查脱敏文本，再点击发送到本地模型。改动输入或模型配置后需要重新预览。

规则识别私钥块、常见访问令牌、云密钥、JWT、带认证信息的 URL、Authorization/Cookie 头和常见密码、密钥、令牌赋值，包括常见环境变量名称。规则不能识别所有敏感格式，预览用于人工去除剩余信息；脱敏可能影响代码完整性，模型应把占位符当作缺失值。

服务端最多保存 8 份脱敏预览，每份有效期 5 分钟且只能发送一次，绑定生成时的配置版本。提问、上下文、预览、输出和计划不写入本地设置文件、任务日志、审计正文或浏览器持久存储；刷新、收起面板和会话锁定后清空界面。模型服务自身的日志由该服务管理。

## 结果与限制

编程建议作为纯文本显示，可下载本次结果。规划模式请求模型按 Schema 返回目标、假设和最多 8 个步骤；每步包含命令、用途、模型标注的影响及验证方式。响应必须通过 Schema 校验。影响标注来自模型，仍需人工检查。导出 JSON 明确 `executed: false` 与 `requiresReview: true`；此面板不提供执行命令、修改文件或调用模型工具的入口。

问题最多 4000 字符，上下文最多 20000 字符，拼接后最多 64 KiB；响应最多 1 MiB，建议正文最多 65536 字符。请求超时可设 10–300 秒、生成长度 128–8192 token；一次只处理一个模型请求。可取消请求，切换配置、锁定、离开面板和关闭服务也会中断正在等待的连接。网络取消是否立即停止底层推理由模型运行时决定。

非完整响应、工具调用、远程转发声明和不符合 Schema 的计划会被拒绝。文本达到输出长度时显示截断提示。所有模型输出均需在实际项目中验证，Sakura 不把它标记为已执行或已测试。

API 为受会话和本机凭证保护的 `GET /api/assistant` 与 `POST /api/assistant`，POST 支持 configure/models/preview/generate，OpenAPI 与 SDK 包含请求合约。配置保存采用版本检查，不会覆盖另一个窗口已经保存的新版本。

回归通过本机 HTTP 协议服务验证发现、预检、脱敏、生成、结构化计划、大小限制、并发、取消及关闭；浏览器验证预览失效、纯文本显示、导出和手机布局。开发机默认端口没有 Ollama，本批未下载或运行真实模型，真实模型的生成质量及速度需要在配置模型后验证。
