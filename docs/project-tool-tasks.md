# 项目工具探测与受限命令

开发工具面板的 Git、Node/npm、Python/pip、Rust/Cargo、Go、Java 和 PHP 版本探测，以及项目清单标记读取，使用原项目持久 UID/GID、独立 home、目录与网络。一次探测共用一个完整短任务，时限 20 秒。原生启动器固定原目录描述符，标记以固定相对路径读取；项目运行时与环境只在降权后生效。

请求在异步读取前固定原项目及 live 身份，复制保留非枚举项目标识，准备租约核对原配置和运行身份，环境只解析一次。命令与环境经有界保护帧传输。结果返回前复核原绑定，完整任务域及准确账号票据清理后才释放租约；清理失败保留 503、错误码和原因。实例或配置改变不转向新项目；既有 root 目录需明确应用 [目录迁移](project-directory-migration.md)。

开发工具安装继续属于实例管理。它固定原 live 和发行版，只安装工具目录列出的软件包，清空环境并在 `/` 使用系统 apk/apt。只接受实例已应用的管理员 HTTP(S) 代理白名单，代理和安装脚本通过有界 stdin 传输；不加载项目 PATH、home、环境或配置。软件源与软件包自身的安装钩子属于实例管理范围。

能力中心的 `syscall-profile` 保留 `restricted`、`networkless` 两种策略。`status` 检查系统依赖和固定 helper，`install` 明确安装依赖；`run` 需要 `command` 与 `confirmed=true`。实际命令及 seccomp 策略执行器经保护帧在原项目账号下运行，保留原参数、退出码、日志脱敏和 1–300 秒时限，整个 cgroup 的清理由完整项目任务域负责。

系统 seccomp 准备及自检使用清空环境、固定目录和隔离系统 Python，不加载项目环境。helper 发布前逐级核对系统目录的 root 归属、权限与非链接类型；状态读取核对固定文件的归属、模式、单链接、长度及摘要，自检只执行产品内可信源码。原客户机运行身份变化会停止后续安装步骤。取消和冻结异常不掩盖原始取消或清理错误。

正文与项目环境受原生 64 KiB 合计上限约束，超限明确返回 413，不拆成部分执行或转由管理员运行。当前正式本地验证包含工具探测/安装 22 项，以及 seccomp、Git 取消与 Jobs 清理的 80 项回归；类型检查及三个生成 Python 正文的静态语法检查通过。本次尚未运行新的客户机 UID 或软件包安装联测。
