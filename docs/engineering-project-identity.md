# 工程操作的项目账号

工程扩展中的工作区文件、归档、Git、测试、代码搜索、命令宏和 Runbook 等操作，通过固定项目启动器使用原项目的持久 UID/GID、独立 home、目录与网络。平台能力中的分片测试、跨实例测试矩阵和环境指纹也复用这一入口。参数仍按各操作的严格 schema 校验，未知执行器明确拒绝。

提交同步固定原项目与客户机 live 身份，准备租约捕获一份原始配置。环境与密钥只由这份配置解析；执行、导入收藏命令和直接工程操作的结果保存期间复核原绑定。取消等待完整任务域及账号票据清理；清理未确认的原 503 与错误码继续向上返回，不转换为普通检查失败。

可信 Python 执行器不再写入 root 临时脚本。源码与请求分别压缩并绑定长度和 SHA-256，再随命令及项目环境进入有界保护帧；解压、检查和执行发生在降权后。解码拒绝损坏、额外压缩数据与超限展开，root 启动参数不携带项目命令、环境或秘密。执行器源码最多 256 KiB、压缩后 48 KiB，请求最多 64 KiB、压缩后 16 KiB；命令最多 65,536 字节，完整原生正文最多 128 KiB，结果最多 8 MiB。

`guest-clock-policy`、`static-routes`、`packet-capture` 是现有明确的实例管理操作，继续使用固定管理员入口。它们只调用校验后的 `date`、`ip` 或有界 `tcpdump` 参数，不加载项目配置、环境、密钥、钩子或工作目录。入口固定清空环境、工作目录 `/` 与系统工具路径，请求经有界标准输入运输；私有网络操作仍复核并进入原项目命名空间。

直接工程操作的 `onResult` 保存回调在准备租约内执行。跨实例矩阵和其他平台能力各子任务按自己的原项目执行；外层聚合与其最终结果保存沿用原有能力任务流程，不声明持有所有子任务的准备租约。轻量代码诊断也已接通项目账号，见 [代码检查](development-next.md)。Notebook 也已使用项目账号，见 [Notebook 环境](notebook-environments.md)。独立语言服务和调试适配器、Git 工作台及其他尚未迁移入口另有范围，不能据此承诺所有扩展都已使用上述账号合约。

项目目录须已允许原项目账号访问，历史 root 目录按 [目录迁移](project-directory-migration.md) 明确核对和应用，工程入口不自动改属主或放宽权限。完整运行与核销规则见 [项目账号](project-identities.md)，网络范围见 [项目网络隔离](project-network-isolation.md)。
