# 脱敏数据包捕获

在能力中心选择运行中的实例，打开“数据包捕获”，填写参数后提交。客户机需要 Python 3.9+、`tcpdump` 和抓包权限；Alpine 可用 `apk add python3 tcpdump` 安装工具。默认在 `eth0` 上采集 5 秒、最多 100 个数据包。`interface` 也可选 `any`，`protocol` 可选 `any`、`tcp`、`udp`、`icmp`；TCP/UDP 等过滤可再指定 `port`。单次最多采集 20 秒、200 个数据包。

结果显示捕获数量和协议分布，“导出完整结果”下载 JSON 诊断报告。报告包含按首个数据包起算的秒级计数、最多 20 条有向流的临时 `peer-N` 标识以及停止原因。标识只在本次报告内有效，不能用于跨次关联。报告不包含 IP/MAC 地址、域名、原始包或载荷；原始 `tcpdump` 输出仅在客户机执行期间用于解析，结束后关闭临时文件。若需要原始 PCAP，应在客户机内自行执行抓包并按自身数据处理要求保存。

所选网卡不存在或客户机未授予抓包权限时，任务失败并提示检查环境；在时限内没有匹配流量时会返回零包报告。抓包只覆盖该实例客户机可见的流量，不代表宿主或其他实例的完整网络视图。
