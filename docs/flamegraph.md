# 客户机性能火焰图

在运行中的实例打开“能力中心”，选择“火焰图生成”，设置采样秒数（1–10）和每秒频率（10–99 Hz），提交后可下载 SVG。横向宽度表示采样占比，调用栈由下向上排列；任务结果还列出采样数和热点函数。

执行器在客户机运行 `perf record` 和 `perf script`，临时数据保存在客户机 `/tmp` 并在命令退出时清理。客户机需要安装 `perf` 并允许性能采样；Sakura 不自动安装或调整内核权限。采样输出限制为 750 KB，最多聚合 2000 次采样、6000 个图形节点，超出时结果标记为截断。采样失败或没有调用栈时明确报错，不生成虚假的火焰图。
