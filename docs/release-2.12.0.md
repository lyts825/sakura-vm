# 2.12.0 · 第七批二十个完整插件包

本次从检出的 2.8.1 升级到 2.12.0，新增 20 包、285 个内部插件及独立领域服务。完整目录为 486 插件、46 包；默认选择为空，宿主 API 保持 5。各包成员、功能、页面、HTTP、CLI 和容量见[使用指南](seventh-plugin-packs.md)，工具镜像见[准备指南](seventh-tool-images.md)。

## 变更

数据质量、血缘、实体归并、时间、地理、图分析和实验提供固定算法与可复查证据。特征、训练、求解、提取、设计系统、表单和通知形成完整创作流程。调度、扩展、依赖、协议、副本和多服务分别提供模型判断、真实固定工具或客户机执行。

285 个插件分别拥有材料、定义、计算、审阅、版本和交换数据，通过显式依赖调用原提供者。新包互无必需依赖；22 个本体固定计算或执行接口逐项登记。旧五类执行服务继续使用冻结 DTO，新增四类使用独立接口。

工作台包含结构编辑、显式字段投影、固定计划、材料续传、结果分页、取消和恢复。地理与图结果提供离线 SVG，设计产物采用无脚本和网络权限的静态 iframe；表单试填通过原领域端口保存回答、计算值及导航判断。身份、空间或代次变化会撤销旧请求和私有缓存。完整扩展目录的侧栏现在可以滚动访问。

原生工具随 Windows x64 运行包交付，固定 Python、11 个包、Tesseract 和语言资源；辅助程序使用 AppContainer、原子 Job 归属及持久原进程身份。原任务结果先保存并关联固定证据，再确认删除暂存和核销预留。恢复只处理原资源，重复批准返回原结果。

四类工程 VM 从显式镜像创建断网副本，记录真实工具、准确 VM、输出摘要及清理。业务完成和资源核销分别记录。每个档案最多一个活动或未核销会话，额度不足会拒绝执行；验证环境显式配置 32 GiB 总套件预留，产品默认仍为 8 GiB。

交接支持 64 MiB、多材料拥有者和完整引用子图。离线 CLI 直接运行编译 JavaScript，不依赖源码、TypeScript 或宿主。导入生成新空间，外来结果与意见保持参考身份，批准、活动会话及凭据不迁移。

接口文档继续保存完整模式；宿主改用约 1.4 MB 的去重运行索引，避免直接解析约 80 MB 文档的类型字面量。完整目录在实际编译态激活时未报告插件错误。

## 验证与交付状态

当前整版交付验收进行中。已验证 60 个 HTTP 模板、20 包交接、真实 VM 与领域算法；剩余安装态、最终门禁、版本冻结及 Git 结果将在本节登记。源码仓库的 `PROJECT_STATUS.md` 同步记录实际证据。

已发现并修复编译 worker 相邻路径、页面重复 `/api` 前缀、VM 完成与清理之间的窗口、原型字段静默丢弃，以及原生准备失败时覆盖原错误等问题。原失败记录保留，复验按受影响范围执行。

已有插件管理回归的替身缺少清单中声明的第二个快照服务，补齐替身后该文件三项通过，其余相关十四项中的已过检查保持通过。运行包没有增加开发依赖。

## 兼容与范围

包保持实验性。原生工具和真实客户机监管的已验证平台为 Windows x64；其他平台保留明确不支持结果。大材料可以保存和交接，首版单材料进入计算限制为 1 MiB；完整解析计划为 2 MiB。领域专有上限、方法与科学判断适用范围见使用指南和设计详情。

本地 Git 提交、服务契约基线和标签在最终交付时记录；本地标签不代表外部发布、推送或部署。本轮不合入其他分支的第四至第六批实现，也不重跑无关外部 BMC、多物理节点或模型部署验收。
