# 快照时间线与差异

在实例的「快照」页选择一个起点快照、终点快照或当前磁盘，再选择客户机路径与分区编号。实例必须停止。默认检查 `/workspace` 和整盘文件系统（分区 0）；分区磁盘可改为 1–128。比较任务在后台运行，进度、取消和历史可从快照页及任务中心查看，完整结果可下载为 JSON。

服务先用 `qemu-img convert -l` 提取所选历史状态，再在网络隔离的临时 Alpine 系统中只读挂载两块磁盘。ext3/ext4 挂载使用 `ro,noload`，不会重放日志。普通文件按 SHA-256 内容和长度比较，符号链接按目标比较；新增、删除、修改分别列出。`qemu-img compare` 同时检查整个虚拟磁盘的逻辑内容，因此文件清单相同但文件权限、目录元数据、分区或其他路径发生变化时仍能看到磁盘不同。文件差异目前不比较权限、所有者、时间戳和目录元数据。

自动挂载仅支持 ext2/ext3/ext4。一次最多列出 5000 个普通文件与符号链接，单次客户机命令输出上限 1 MiB，扫描和磁盘比较总时间上限 10 分钟；超过限制会报错，不会把不完整结果标成完成。大目录应缩小比较路径。虚拟磁盘转换本身单次最长 30 分钟，临时盘会在任务完成、失败或取消后删除；异常断电后可清理数据目录 `plugins/snapshots/diff-*` 中遗留的临时文件。

接口（需启用磁盘快照插件）：

```text
GET  /api/vms/:vmId/snapshot-diff
POST /api/vms/:vmId/snapshot-diff
GET  /api/jobs/:jobId/result
POST /api/jobs/:jobId/cancel
```

提交示例：`{"from":"<快照 UUID>","to":"current","partition":0,"path":"/workspace"}`。`to` 也可为另一个快照 UUID；`path` 必须是客户机文件系统内的绝对路径。任务结果包含 `diskChanged`、文件数量和每个变化条目的路径、类型、大小与 SHA-256 或符号链接目标。快照和当前源盘保持只读，临时救援实例在完成后清理。
