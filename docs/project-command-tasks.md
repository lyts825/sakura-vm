# 收藏命令与流水线的项目账号执行

收藏命令和流水线步骤使用当前所选项目的持久 UID/GID、独立 home、原目录及网络模式。命令正文、参数和解析后的环境只进入有界保护帧，经固定启动器完整验收并降权后执行，不拼入 root Shell 参数。项目账号与目录迁移必须已就绪；缺失目录、未完成迁移和暂停中的实例会拒绝执行。

提交固定原项目标识；执行准备捕获一份配置和准确 live 实例，私密配置及运行时只解析这份配置。更改已保存的活动项目不会改变该次运行。流水线全部步骤使用同一份配置，各步骤独立发行任务 UUID 和完整 cgroup 票据，并遵守各自的超时。两步之间不会重新解析环境或密钥。

准备租约持续到运行和清理结束；流水线还将租约保持到产物收集与最终记录保存完成。这期间不能修改原项目目录或网络模式。取消和服务停用先等待完整任务域清理，再释放租约；借用的终端服务不会被关闭。原生清理未确认时，持久账号票据继续保护绑定，后续准备按原归属恢复，不把取消改记为成功。

输出和错误消息遮盖项目私密配置。普通命令非零退出仍显示失败。清理未确认保留原 503 分类和具体错误码；流水线同时持久保存该次运行及失败步骤的错误码，重载后仍显示失败，后续步骤和产物收集不继续执行。产物仍通过现有文件服务收集，单文件上限 32 MiB、一次运行总计 64 MiB；这次迁移覆盖步骤执行，不增加文件服务的访问边界。

`tests/project-command-tasks.test.ts` 使用真实宿主项目配置、准备租约和持久记录，注入任务执行器验证配置捕获、参数、项目切换、实例替换、目录迁移门闩、绑定保护、超时、取消、关闭及清理错误重载。该宿主检查不替代 Linux 原生 UID/GID 实测；固定启动器与终端的实际客户机检查见 [项目账号](project-identities.md) 和 [项目终端](project-terminals.md)。专属项目 SSH、系统 cron、用户管理器与其他扩展仍按各自入口处理，整体覆盖继续见 [未完成功能](unfinished-features.md)。
