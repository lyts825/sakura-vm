# 团队模板

能力中心的“团队模板”保存可复制的实例资源和项目设置。模板保存在当前 Sakura 主机，最多 40 个；修改同一模板会递增版本。模板复制 CPU、内存、磁盘容量、发行版、固件、加速器、项目运行时、公开 HTTPS 仓库地址和预览端口。为避免意外传播密钥或占用端口，不复制环境变量、私密配置、服务命令、安装命令、启动命令、原项目目录、客户机文件及端口转发；新项目目录为 `/workspace`。

1. 在来源实例和项目运行 `{"mode":"capture","name":"模板名称"}` 的“检查”，审阅返回的 `content` 和 `fingerprint`。
2. 用相同参数加上 `fingerprint` 运行“执行”以保存模板。更新已有模板时再传 `templateId`；检查结果中的 `previousFingerprint` 也必须在执行时传入，以拒绝覆盖他人的新版。
3. 用 `{"mode":"list"}` 查看模板目录，或用 `{"mode":"inspect","templateId":"..."}` 检查内容。创建新实例前可用 `mode:create` 的“检查”再次审阅模板。
4. 用 `{"mode":"create","templateId":"...","fingerprint":"...","targetName":"new-name"}` 运行创建。Sakura 新建独立虚拟磁盘与身份，将模板项目设置写入新实例；随后照常启动并运行项目设置。创建失败会清理新实例。
5. 删除模板须用 `mode:delete`、`templateId` 和当前 `fingerprint`。删除目录记录不会删除已创建实例。

模板来源或已存内容的指纹变化会使旧请求失败。保存的内容会校验 SHA-256，损坏的模板目录不会被静默使用。模板目前是本机目录，尚不提供多用户身份或跨主机发布；对应权限和集群功能仍在未完成清单中。
