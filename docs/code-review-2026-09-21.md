## 已修复问题

| 问题与触发条件                                                        | 修复结果                                                                                   |
| --------------------------------------------------------------------- | ------------------------------------------------------------------------------------------ |
| 启动或磁盘操作尚未结束时关闭服务；启动/退出状态保存失败               | 关闭等待已经开始的操作；失败时仍清理运行状态并完成退出通知                                 |
| 克隆首次启动前创建快照，轮换密钥后恢复或再次克隆                      | 快照保存配套私钥、初始化镜像与待轮换身份；恢复、克隆使用对应身份                           |
| 首启密钥轮换过程中中断                                                | 先让新公钥在客机落盘，再原子保存主机私钥，最后移除旧公钥；停止等待启动任务收尾             |
| SFTP 断线后清理回调不再返回；读到 EOF 后远端关闭仍可能报错            | 连接错误及时结束外层操作；文件读取等待句柄关闭，并保留错误处理                             |
| 取消上传/同步时先断开 SSH，留下临时文件；同步断线后仍可能发布本机文件 | 连接建立阶段与传输阶段分别处理取消；普通取消保留清理通道，真实断线触发传输取消及提交前检查 |
| 同步覆盖既有文件导致所有者或特殊权限位丢失                            | 替换前恢复 uid/gid 与完整权限；恢复元数据失败时保留原文件                                  |
| 下载开始后源文件增长，实际传输超过声明长度                            | 读取范围限定到初次 stat 的大小，空文件不打开后续增长的数据流                               |
| 导入接受仅含公钥的身份；导入、克隆与请求断开/关服交错                 | 要求有效私钥，传递取消信号，在发布实例前检查取消；服务关闭等待请求清理                     |
| 1 MiB 合法文本经 JSON 转义后超出通用请求体上限                        | 文本保存单独计算请求体上限，继续保留 UTF-8 内容字节限制                                    |
| 畸形 WebSocket 地址或 QMP JSON；QMP 协商失败、断线、UTF-8 分片        | 无效地址安全拒绝；协议错误转为可处理的失败，断线及时结束并正确解码分片文本                 |
| CLI 导出失败遗留半成品，同名重试失败；已有目标仍触发昂贵导出          | 先独占创建目标，失败清理本次创建的文件，成功保留完整内容                                   |
| 文件目录切换保留旧列表；保存期间继续输入被完成响应清空                | 切换目录立即作废列表与响应；保存完成只关闭已提交草稿，保留后续输入                         |
| 并发关闭终端、关闭请求期间切换页面后标签复现                          | 原子更新标签与活动会话；按实例共享状态，关闭成功后持久化最新列表，保留期间的新标签与编辑   |
| 慢轮询一直被更新的请求序号作废；桌面旧响应覆盖停止后的状态            | 根据已经应用的响应判定过期；生命周期变更时作废请求并取消桌面请求                           |

| 终端卸载后回调/动画帧继续执行；同步监听器残留；窄窗口工具栏溢出       | 清理对应资源，工具栏允许换行                                                               |

## 兼容性与运行说明

旧快照没有配套身份文件时继续使用当前身份；如果旧版本已经永久丢失某个历史快照需要的私钥，无法凭空恢复。新建快照会保存对应身份。

普通上传取消会清理远端临时文件；真实 SSH 连接断开后，无法通过失效连接保证删除远端临时文件，原目标文件受到原子替换和取消检查保护。

现有后端进程需要重启才会加载本轮服务端代码，前端需要刷新。以上审核与测试覆盖确认的问题，不构成对所有环境、所有并发组合均无缺陷的保证。
