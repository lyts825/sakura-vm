# 文件锁

启用文件工作台插件，打开一个文本文件，在编辑器中选择“获取文件锁”。锁定状态显示到期时间；编辑器每 45 秒续租。保存时自动携带此次锁的令牌。可随时选择“释放文件锁”；关闭编辑器或离开文件面板也会尝试释放，意外断线则最多两分钟后到期。

锁按实例和规范化后的 Linux 路径生效。文件与包含它的目录不能同时被不同编辑器锁定；同一实例最多保留 128 个租约。Sakura 的文本保存、上传提交、历史恢复、重命名和删除在服务端检查路径及祖先/子孙冲突；写入与获取新锁串行，避免在写入过程中抢占。锁令牌不保存在浏览器草稿或服务器文件中，服务重启后旧令牌失效。已过期的令牌不会默默退化为无锁写入。

锁约束 Sakura 文件 API，不能阻止客户机终端、Git 或其他程序直接改写文件。文本保存仍用版本摘要检查外部更改；直接上传不具备文本三方合并。符号链接别名按请求路径分别判断，不能把路径锁当作客户机文件系统的强制锁。

接口：`GET /api/vms/:vmId/file-lock?path=...` 返回锁定状态和到期时间，不返回令牌；`POST` 接受 `acquire`、`renew`、`release` 操作，后两项需要获取时返回的令牌。冲突使用 HTTP 409。`npx tsx --test tests/file-locks.test.ts tests/plugins.test.ts` 覆盖排他、过期、续租、写入串行和插件路由；浏览器回归覆盖编辑器取锁并带令牌保存。
