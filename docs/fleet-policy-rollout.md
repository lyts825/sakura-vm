# 集群策略发布

此功能将[插件功能灰度](feature-rollouts.md)策略发布到已配对的 Sakura 主机。目标先启用 HTTPS 同伴入口并完成单向配对，然后在“系统设置 → 主机配对与多主机状态”的入站主机列表，对该来源单独开启“允许策略发布”。新配对默认没有此权限，撤销后无法查询或继续发布。身份由已配对的 TLS 证书指纹、远端主机 ID 和独立凭证校验。

来源主机在“系统设置 → 集群策略发布”选择插件、启用状态、灰度百分比、分桶版本和目标，点击“保存待发布批次”。此时仅查询各目标当前插件策略修订，保存目标身份和原修订供复核，不修改目标。随后点击“发布或重试批次”，服务再次读取目标；只有身份与原修订一致才保存策略。每个目标单独记录成功或错误，批次以及逐目标结果写入本机数据目录，重启后仍可查看和重试。请求结果不明确时，重试会核对目标已保存的修订和完整策略，避免重复写入。目标策略在审阅后被其他操作更改时，会显示版本冲突；需建立新批次。

每批最多 16 台目标，最多保留 50 批。一次发布可能部分成功；已成功目标不会再次写入，失败不会回滚其他目标。目标保存后，灰度选择在其下次启动 Sakura 时生效，且仍取决于目标插件是否已在插件中心选中。来源主机可通过 `GET/POST /api/fleet-policy-rollouts` 查看及创建/发布批次，目标同伴入口使用受限的 `GET/POST /peer/rollouts`。API 请求结构在 OpenAPI/SDK 中。
