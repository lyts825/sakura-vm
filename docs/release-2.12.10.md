# 2.12.10 · 区域格式与 API 文档性能优化

本次从 2.12.9 升级到 2.12.10，日期为 2026-10-29。状态：已完成。

## 范围

默认日期、数字和固定小数位数复用格式器。时区验证、日期格式器和数字格式器各自最多保留 32 项，按先入先出淘汰。每次调用仍读取区域偏好；未设置有效时区时，继续读取系统时区。显式格式选项、无效日期和特殊精度沿用原处理。

API 文档生成时跳过普通空 strict 对象的结构转换。18,632 个查询和请求头结构中，18,354 个符合跳过条件，约占 98.5%。有字段、元数据、校验或自定义行为的结构继续由 Zod 转换。这项改动没有增加缓存，原文档响应缓存和动态插件状态保持不变。

## 性能

基线为 2.12.9 的 `eb17dd5b`，环境为 Windows x64。两处基准错开执行，各取 5 对交替样本的中位数。

| 测量范围 | 改动前 | 改动后 |
| --- | --- | --- |
| 已保存偏好：1,000 次默认日期格式化 | 99.0 ms | 1.4 ms |
| 已保存偏好：1,000 次默认数字格式化 | 75.3 ms | 0.7 ms |
| 已保存偏好：1,000 次固定精度格式化 | 71.9 ms | 0.7 ms |
| 未设置偏好：1,000 次默认日期格式化 | 60.8 ms | 32.7 ms |
| 未设置偏好：1,000 次默认数字格式化 | 42.6 ms | 33.3 ms |
| 未设置偏好：1,000 次固定精度格式化 | 48.2 ms | 35.2 ms |
| API 文档首次构造 | 182.84 ms | 89.59 ms |
| API 文档预热后重新构造 | 197.66 ms | 72.09 ms |

格式化数据来自 Chromium 153，每种场景预热 30 次，只计函数调用。未设置偏好时，单独读取偏好的耗时约为 29.8 → 30.6 ms，基本不变；保留系统时区的实时性优先。

文档数据来自 Node 24.15。首次构造的每个样本使用独立进程，预热构造使用同一进程；两组均不计模块初始化、JSON 序列化和 HTTP。已有响应缓存命中时无需再次构造文档。上述数字不代表完整页面或业务请求的端到端加速。

## 验证

区域格式的 Node 差分检查通过 21,361 次，Chromium 差分检查通过 3,672 次。覆盖语言与数字区域、夏令时、无效日期、显式选项、存储异常、直接改写和缓存上限。跨标签偏好更新及同页系统时区切换通过，未发现浏览器异常。

API 文档通过 18 组差分检查。五组插件状态、端口和目录版本下，完整文档及 SDK 字节一致；元数据、继承字段、符号字段、特殊 catchall、自定义导出和返回参数隔离也通过。既有 OpenAPI 8 项、网关 14 项测试全部通过。

完整生产构建和 TypeScript 检查通过。架构检查覆盖 2,569 个模块；605 个服务声明、486 个插件、46 个包、9,316 条 HTTP 和 6 条 WebSocket 契约检查通过。繁体资源的 6,930 条短语与 116 个动态片段同步检查通过。

区域偏好和 API 浏览器两项既有回归全部通过，用时 30.8 秒。编译版生产验收通过，覆盖 7 组插件组合、生产内容安全策略下的页面与媒体、离线读取、跨标签锁定、本地 Webhook 和助手协议，以及独立网络入口与 worker。

发行检查覆盖 1,011 个服务模块。首屏主 JavaScript 为 632,877 字节，初始静态资源为 1,378,629 字节，均在原 950,000 和 1,650,000 字节预算内。版本一致性及 259 个本地文档链接检查通过。

测试脚本、报告与日志保存在已忽略的 `artifacts/performance-2.12.10/`，没有新增跟踪测试材料，也没有修改既有测试。初期浏览器夹具的时区覆盖冲突已修正，最终差分通过。未运行全量测试、真实 VM、其他平台或长期整机负载验收。
