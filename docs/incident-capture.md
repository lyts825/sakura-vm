# 事件证据的只读采集

目标版本为 2.8.0，当前处于实施阶段。原指标、健康插件已提供独立快照服务，事件证据领域已接通预览、批准和固定保存；事件包尚未登记，页面、HTTP 和 CLI 仍待整合。

## 支持的来源

| 来源 | 采集内容 | 当前范围 |
| --- | --- | --- |
| 指标 | 原指标插件的 CPU、内存、磁盘、网络及进程采样 | 正在运行的 VM；保留原 sampledAt 和缓存规则 |
| 健康 | 原健康插件的服务状态、检查时间及失败记录 | 正在运行的 VM 的默认项目；不复制任务日志 |

原插件缺席时，证据页仍可接收上传和人工观察。上传的相同 JSON 会标为外来声明，不能取得原提供者的采集身份。

当前目标必须明确填写 VM ID 和 `projectId: "default"`。其他项目与停止状态的 VM 会被拒绝，未将它们计为已支持范围。

## 固定和核对

预览在原提供者的受管执行窗口中读取一次快照，并保存完整内容。凭据绑定实际账户、事件证据消费者及其代次、原提供者代次、VM 进程和执行身份、网络代次，以及适用的配置摘要。原提供者使用本激活代次的密钥校验凭据，五分钟后失效。

批准绑定事件案例的固定修订和预览。提交在复制前后核对原凭据，保存实际字节及摘要；案例范围变化、权限撤销、运行身份改变或提供者换代都会拒绝新提交。重复提交已完成的批准返回原记录。

`sourceAt` 保存指标原采样时间，`observedAt` 保存原提供者读取快照的时间，字节记录保留复制入库时间。健康快照保留各项原检查时间，不把读取时间写成新一次健康检查。

每份来源快照最多 512 KiB，超过范围时明确拒绝。采集完成后形成固定历史材料；VM 后续变化不会改写已保存的内容。离线导入继续按外来声明处理，采集凭据只在原激活代次内校验。

## 验证范围

本阶段通过实际服务代理和受管执行作用域检查篡改、过期、账户/消费者、运行代次、配置变化、体积上限和案例修订。真实 VM 验证了指标采样、默认项目的健康只读视图、固定字节保存、重启后拒绝旧凭据及历史证据保持。健康实测使用空服务配置；未将其解释为已覆盖真实服务故障场景。

两个专用测试 VM 均已核对原创建身份并删除。验证材料保存在 Git 忽略目录，未写入正式源码或插件资源。
