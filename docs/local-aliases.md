# Windows 系统域名解析

网络插件的“服务与端口”页可为入口生成稳定的 `app-<规则 ID>.sakura.localhost` 别名。浏览器通常能直接访问 `.localhost`；若希望命令行客户端和其他本机程序也能使用这些名称，在同一页明确启用“Windows 系统域名解析”。Sakura 会把当前启用别名逐条映射到 `127.0.0.1`，入口仍只监听本机回环地址。

Windows hosts 文件位于 `%SystemRoot%\System32\drivers\etc\hosts`，修改它需要管理员权限。普通权限下启用或同步会显示失败原因，设置和待同步列表保留；以管理员身份运行 Sakura 后点击“重新同步”即可重试。Sakura 只写入带 `BEGIN/END SAKURA LOCAL ALIASES` 标记的区块，不覆盖其他条目。关闭功能会移除这个区块；新增、修改或删除入口时，已启用的系统别名会自动更新。同步后还会用 Windows 系统解析器核对每个域名是否指向 `127.0.0.1`，验证失败会保留可见错误。若区块被修改、标记不完整、外部 hosts 条目将同名域名映射到其他地址，或 hosts 文件编码不是 UTF-8，Sakura 拒绝改写并要求人工检查。

hosts 文件不能表示通配域名，因此系统解析只同步实际创建的入口别名。HTTPS 自签名证书的信任仍需单独处理；系统解析不会自动信任证书，也不会开放外部网络访问。状态卡显示已安装、待同步、待移除和失败原因。
