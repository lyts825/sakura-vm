# 移动伴侣

移动伴侣是运行在手机浏览器中的只读页面。它通过主机配对功能的独立 HTTPS 监听器提供，不开放 Sakura 的本机控制 API，也不提供启停、终端或文件操作。

1. 在电脑端启用“账户与只读分享”，以管理员登录。
2. 在“主机配对与多主机状态”启用 `0.0.0.0` 局域网 HTTPS 监听，然后重启 Sakura。该入口的端口须能从手机访问；它与只监听本机的控制面端口不同。
3. 在“账户与只读分享 → 移动伴侣”选择可见实例和告警类型，生成五分钟有效的一次性配对码。
4. 手机打开 `https://主机局域网地址:同伴端口/mobile/`，核对页面证书的 SHA-256 指纹与电脑端显示的一致后，输入设备名称与配对码。当前同伴证书为本机自签名证书，手机浏览器可能要求先手动信任。

配对成功后，手机每 30 秒或按“刷新”读取一次状态。凭证放在 `Secure`、`HttpOnly`、`SameSite=Strict` Cookie 中；服务端仅存其 SHA-256 摘要，30 天后过期。管理员可更改每台设备的实例与告警范围、暂停只读访问或立即撤销。手机“断开此设备”也会在服务端撤销凭证。更换管理员密码会撤销全部移动设备；控制面会话锁定或数据目录迁移期间，读取和配对均被拒绝。

手机只收到已授权实例的名称、状态，以及所选告警的类型、时间和确认状态。告警消息、任务日志、命令、文件路径和私密配置名称不发送给手机。它显示应用内告警列表，不提供后台推送或系统通知。断网时不会展示过期数据为实时状态。

管理员接口是 `GET /api/mobile-companion` 和 `POST /api/mobile-companion`（`pair`、`policy`、`revoke`）；手机同源接口为 `/mobile/connect`、`/mobile/feed` 和 `/mobile/disconnect`。这些路径仅由独立 HTTPS 同伴监听器提供。连接码按来源限速，单个配对码只能使用一次，最多保留 16 台未过期设备。手机页面使用限制性 CSP，不渲染服务器消息为 HTML。

验证：`tests/mobile-companion.test.ts` 覆盖配对码、跨来源拒绝、限速、持久策略、范围过滤、撤销与断开；`e2e/mobile-companion.spec.ts` 在真实 HTTPS 监听器和手机宽度浏览器中完成配对与只读查看。
