# 在线迁移前置检查

能力中心的“虚拟机在线迁移”检查读取运行中实例的 QEMU 状态、版本和迁移任务状态，并刷新已配对主机的资源评分。没有指定目标主机时选择一个合格同伴；也可在 `POST /api/vms/:vmId/next-features` 的 `check` 请求中传入 `options.targetHostId`。结果包含候选主机、逐项阻断原因及迁移步骤，不会修改实例或发送数据。

当前实现只生成计划。目标侧暂停接收进程、经认证的 QEMU 状态通道、在线磁盘脏块同步与校验、防止两端同时写入的切换栅栏尚未实现。即使源和目标的当前资源都满足要求，结果仍为 `ready: false, executed: false`；不能把冷迁移或快照复制当作在线迁移。目录状态因此保留“部分实现”。跨主机移动可使用已有的[冷迁移队列](cold-migration.md)，但需要先停止源实例。
