# 浏览器扩展

Sakura 附带一个 Chromium Manifest V3 扩展，用于只读查看本机实例的名称、状态、发行版和 CPU、内存、磁盘规格。扩展不会启动、停止或修改实例，也不能访问普通管理接口。

先在 Sakura 的“系统设置 → 账户与只读分享”启用账户模式，并以管理员登录。在 Chrome 或 Chromium 的扩展程序页启用开发者模式，选择源码或运行包中的 `browser-extension` 文件夹，作为“加载已解压的扩展程序”安装。管理员随后在“浏览器扩展”区域生成配对码，在扩展弹窗输入 Sakura 端口及配对码即可连接。配对码五分钟内有效且只能使用一次；重新生成会使旧码失效。

扩展只申请本机 `127.0.0.1` 的 HTTP 主机权限和本地存储权限。配对后的随机凭证保存在扩展自己的本地存储中，服务端只保存其 SHA-256 摘要，凭证三十天到期；到期后需重新配对。管理员可在设置中查看最近连接状态并立即撤销连接。更换管理员密码会撤销全部扩展连接；会话锁定期间扩展读取也会被拒绝。弹窗中的“清除本地凭证”只清除当前浏览器存储，若要服务端立即失效，还应在 Sakura 中撤销连接。

扩展使用显式扩展来源和专用只读接口；普通管理接口仍需同源账户凭证。扩展仅连接同一台计算机的 Sakura，不提供远程访问或浏览器应用商店自动安装。

验证：`npm run test:browser-extension` 使用真实 Chromium 扩展测试配对、实例摘要、来源绑定、普通接口拒绝、配对码重放拒绝和撤销；`npm test` 覆盖过期、错误凭证和持久化行为。
