# 项目语言服务与调试器

启用“代码检查”插件后，文件编辑器支持 TypeScript、JavaScript 和 Python 的 LSP 补全、定义、诊断及重命名预览；Python 文件还可通过 DAP 设置断点、暂停、继续、单步、读取调用栈和变量。重命名仍要求已保存版本、文件锁和预览确认，冲突拒绝覆盖。语言服务面板可刷新并停止未结束的原会话，调试器在重载或清理失败后提供“清理上次调试”，完成原清理后再启动。

显式“安装”使用固定管理员入口安装共享工具，不加载项目目录、配置、环境或钩子。npm 使用固定 registry 和精确版本、禁用安装脚本；debugpy 使用固定版本的二进制 wheel。共享资产和版本标记核对 root 归属、权限、链接及路径。旧安装缺少新标记时显示未就绪，需要重新明确安装；状态查询不会安装或执行项目代码。

实际语言服务器、调试适配器、被调试程序与子进程使用原项目持久 UID/GID、独立 home、目录描述符和原网络。请求在首个异步读取前固定原项目、live 和调用者输入，保留非枚举项目 ID，环境只解析捕获配置一次。正文及环境在降权前通过有界保护帧校验；持续二进制 stdin 使用独立原描述符，不混入控制帧。既有 root 目录需要明确应用 [目录迁移](project-directory-migration.md)，缺失目录不自动创建。

LSP 补全/定义请求期限为 30 秒，诊断/重命名为 120 秒；DAP 会话最多 12 小时，创建完成后脱离该 HTTP 请求的取消信号，全局关闭与期限仍有效。SSH 连接就绪后的命令通道应答另有 10 秒预算、取消和连接关闭处理；迟到通道被销毁，原 live 改变不能入场。协议支持二进制、背压和半关闭，EOF 之后保留最终已缓冲响应。

宿主先持久原协议 intent，再登记准确 task/native 票据，元数据位于 `machines/<vm>/project-protocol-streams/<projectId>/<runUUID>.json`。取消、EOF、调试停止和服务关闭都确认整个原 cgroup、所有后代和准确 native 票据清理，完成后才释放准备租约；成功回执移入 `closed/` 历史。丢失启动回执或清理失败保留原 token、记录和租约，返回 503，明确停止可重试。状态只读核对完整原票据，不重连、安装或接管旧协议；冷 boot 只在原控制路径已不存在时退休准确旧资源，不对新 boot 发送旧停止。

HTTP 入口仍为 `/api/vms/:id/language-service` 和 `/api/vms/:id/debugger`。LSP 新增 `{"action":"stop","token":"原运行UUID"}`，DAP 原 stop 格式不变。停止使用真实原记录，不接受标签或 PID 作为权限。共享工具安装属于实例管理；重命名的有限文件读取/上传继续沿用管理员 SFTP、文件版本、锁及回滚范围，不能据此声明所有文件接口已经改为 UID。

正式九个相关测试文件共 229 项通过，包含真实宿主 journal/frame、LSP/DAP framing 与生命周期、GuestTask、缓存资源和清理回归，以及 SSH 命令通道设置的六个取消/超时/实例变更模型；完整类型检查通过。证明为 `.data/protocol-stream-backend-f35b7403-2c96-43e3-aa7f-37a5d89ef009-verification.json`，实际退出 0、对应源码前后未变。本批未启动 VM，真实 Linux UID/GID/home、C launcher、完整 cgroup、发行版共享工具安装还需实测；原 smoke 正在适配，旧 root 结果不代表新账号成功。
