# 2.8.0 版本说明

## 版本与范围

2026-10-25，应用及内置包从 2.7.0 更新至 2.8.0。第三批 10 包、101 个插件均已实现，目录共 201 个插件、26 个包。宿主 API 保持 5，默认插件选择为空；“完整兼容包”包含新增十包。

本版增加兼容功能和独立版本服务，保留旧服务及数据入口。第四批、第五批设计不在本次实现范围。当前为本地构建与验收，尚未推送或对外发布。

五种固定工具共用本体会话，保持独立的消费者、输入、原资源回执和清理权限。输入输出改为有界分块文件，整帧仍核对字节和摘要。每包根账本及执行资源纳入[宿主共同容量](suite-capacity.md)。详细边界见[固定工具执行](suite-execution.md)。

模型调用使用单独的受管协议。跨包动作由原提供者保存票据、执行意图和回执；流程不能绕过原授权，也不能自动重发未知结果。所有交接包均保留来源声明，导入不会赋予本机执行权限。

## 验收与限制

各执行包已完成真实工具和原服务代理验收。浏览器包含三模板、真实像素比较和取消；数据库包含 5,000 行执行和独立恢复；事件包含确认丢失、死信与轨迹篡改；媒体包含透明图、EXIF、视频片段、音频及批次部分失败；学习包含三个模板、失败反馈、先修课和新尝试恢复。

共用执行层已检查超过原管道上限的输入输出、控制器退出与冻结、插件和本体提供者撤权、精确原身份回收。流程已实际调用知识发布和接口执行两个原提供者，并核对一次批准、未知不重发及零残留 VM。

真实本地模型调用验收按用户要求跳过，未下载模型。模型评测的合成协议、权限、取消、一次性发送、规则评分和离线核验已经验证；合成响应不计作真实模型输出。

当前固定 VM 工具面向已验收的 Windows x64 宿主与 Alpine x86_64 工具镜像。缺少依赖、平台不支持或预算不足时明确拒绝，不自动下载工具。默认 8 GiB 共同额度不足以启动最小 8 GiB 虚拟磁盘，需按容量说明明确配置。

新增包保持实验性。交接包通常限 16 MiB，具体输入、像素、文件、步骤和元数据上限见各指南；原设计中的较大预算不代表本版能力。学习记录属于所有者自学，不作认证；浏览器可访问性仅覆盖选定规则。

整版构建、分发检查、安装态验收和冻结基线仍在收尾。最终提交、标签及验证结论同步于 [PROJECT_STATUS.md](../PROJECT_STATUS.md)。新增测试、截图和报告均保存在 Git 忽略目录；既有 CI 测试入口继续保留。
