# 临时反向隧道

在能力中心选择运行中的实例，选择“临时反向隧道”，将参数设为 `{"mode":"open","guestPort":8765,"durationSeconds":300}`。客户机需有 Python 3.9+，目标 TCP 服务应监听客户机的 `127.0.0.1:guestPort`。任务完成后返回宿主机上的 `127.0.0.1:localPort`；可用本机浏览器或 TCP 客户端连接。入口只绑定宿主机回环地址，不向局域网开放，最多允许四个并发连接。

`mode` 为 `status` 时查询当前入口，`close` 时立即关闭。时限可设为 10–600 秒，到期、实例停止、应急锁定或 Sakura 服务关闭时都会关闭监听并断开现有连接。入口及流量不持久保存；服务重启后需要重新开启。隧道本身不增加身份认证，本机其他进程在有效期内也能访问该端口，敏感服务应继续使用自身认证。

此实现通过 Sakura 控制的 SSH 命令通道转发字节，不要求启用客户机的 SSH TCP forwarding，也不会修改客户机 SSH 配置。真实 Alpine/QEMU 验证了客户机 HTTP 服务经本机入口访问、手动关闭与到期撤销。
