# 嵌套虚拟化检测

能力中心的“嵌套虚拟化”检查会在正在运行的实例中读取 `/proc/cpuinfo` 的 `vmx` 或 `svm` 标志、`/dev/kvm` 字符设备、内核版本及本次 QEMU 加速器。两项条件同时存在时报告为“候选可用”；任一缺失时明确报告缺少的条件。检查和运行结果会写入实例能力历史，服务重启后仍可查看。

这是一项客户机可见能力检测，不修改虚拟机配置、安装 KVM 或启动二层虚拟机。候选可用仍需安装客户机 KVM/QEMU 并实际启动二层系统验证。停止的实例不能产生当前检测结果。

`npm run test:nested-virtualization` 在真实 Alpine/QEMU 实例中完成探测和结果持久化；单元回归覆盖有无 CPU 扩展、KVM 设备、停止状态及重启后历史。
